# Game assets

Place game-owned models, textures, sounds, and data files in this directory.
Do not put game assets inside the LaziealRuntime submodule.

## Khronos sample assets

- `Models/Fox/Fox.glb`: animated skinning demo model with `Survey`, `Walk`, and
  `Run` clips. The model is CC0 1.0; rigging, animation, and glTF conversion
  are CC BY 4.0. See `Models/Fox/SOURCE.md` and `Models/Fox/UPSTREAM_LICENSE.md`.
